# Opportunity Automation

Automatización inteligente de búsqueda y filtrado de oportunidades freelance (bounties, gigs, proyectos remotos) usando IA.

## Características
- Scraping de múltiples plataformas de bounties (Opire, Algora, Polar)
- Filtrado por skills, stack, monto
- Clasificación por relevancia usando embeddings
- Notificaciones de nuevas oportunidades
- Dashboard web de oportunidades

## Stack
- Python 3.11+
- LangChain / LLMs
- SQLite
- Streamlit (dashboard)
- Playwright (scraping)

## Instalación
```bash
git clone https://github.com/RanuK12/opportunity-automation
cd opportunity-automation
pip install -r requirements.txt
python main.py
```
